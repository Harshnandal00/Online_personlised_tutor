# 🎓 Online Personalized AI Tutor

An intelligent, interactive learning platform designed to provide personalized study assistance, track homework, explain complex notes, and monitor study analytics using AI.

---

## 🚀 Tech Stack

### Frontend
- **Framework:** React 18 with TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Client Backend Integration:** Supabase JS Client

### Backend
- **Framework:** FastAPI (Python)
- **Server:** Uvicorn
- **AI Model:** Google Gemini API
- **Database & Auth:** Supabase (PostgreSQL with Row Level Security)

---

## 📦 Features

- **AI Tutor:** Interactive chat-based tutoring powered by Google Gemini.
- **Notes Explainer:** Break down complex topics and study notes into digestible explanations.
- **Study Analytics & Achievements:** Track learning milestones, streaks, and progress.
- **Planner & Timetable:** Integrated calendar, timetable, and homework tracker.
- **Secure Authentication:** User management and access control powered by Supabase.
